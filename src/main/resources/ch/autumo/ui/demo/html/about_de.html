autumo UI FX Demo 1.2.0


Diese autumo UI FX Demo-Anwendung ist eine Demonstrationssuite für das autumo UI FX Framework. Sie zeigt die Kernfunktionen des Frameworks wie Application-Shell, MVC-Struktur, Theming, Internationalisierung, Installer, Registration, zuletzt geöffnete Dateien, Konfigurationsverwaltung und Dialog-Panels.

Die Demo basiert auf dem autumo UI FX Framework und dient als Referenzimplementierung für die Entwicklung von JavaFX-Desktop-Anwendungen mit autumo UI.


Wenn Sie mehr Informationen haben möchten, besuchen Sie die Github-Seite für das autumo FX UI Demo.
