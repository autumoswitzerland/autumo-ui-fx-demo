autumo UI FX Demo 1.2.0


This autumo UI FX Demo application is a demonstration suite for the autumo UI FX framework. It showcases the framework's core capabilities such as the application shell, MVC structure, theming, internationalisation, installer, registration, recent files, configuration handling and dialog panes.

The demo is built on top of the autumo UI FX framework and serves as a reference implementation for building JavaFX desktop applications with autumo UI.


If you would like more information, visit the autumo UI FX Demo Github page.
